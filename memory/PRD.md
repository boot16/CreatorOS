# CreatorOS — PRD

## Problem Statement (verbatim, condensed)
CreatorOS — Know what to create next, and who to create it with. An AI system that reads a YouTube creator's own content + performance history, cross-references what's trending in their niche, and tells them the specific next video to make and which other creator to make it with — with reasoning shown, not just the answer. 5-day contest submission, seeded/demo data, no login wall.

## Architecture
- Frontend: React 19 + Tailwind + framer-motion + shadcn/ui, dark-first with electric violet accent
- Backend: FastAPI + MongoDB (relational-style refs via seed_data.py — real Postgres swap deferred)
- LLM: Claude Sonnet 4.6 via Emergent Universal Key (emergentintegrations) — cached in mongo llm_cache collection
- Data-access seams (`get_creator_data`, `get_trends`) ready for real API swap; `DATA_MODE=demo` flag
- Deterministic scoring functions in seed_data.py — NEVER generated by LLM

## User Personas
- Solo YouTube creator (10K–500K subs) seeking their next specific video + collab pick

## Core Features Implemented (2026-02-22)
- Landing page (public, no login) with hero opportunity card as static screenshot
- Onboarding — goals selection, Explore Demo primary CTA, Connect YouTube shows toast
- Animated Creator DNA reveal (6 steps × 550ms staged checkmarks)
- Creator DNA dashboard — pillars, formats, style, audience, 20 seeded videos
- Opportunity Feed — 5 scored opportunity cards sorted by score
- Opportunity Detail — LLM why_bullets + expandable "How was this calculated?" formula breakdown
- Trend Radar — bubble map (momentum × volume) + list view, category filter
- Trend Detail — LLM-generated why/related/audience, links to opportunity
- Idea Lab — real LLM generation: concept + 4 titles + 3 hooks + 5-beat structure
- Creator Profile / Compatibility — Sarah Chen with 92 score, 5 sub-score breakdown, Propose Collab modal
